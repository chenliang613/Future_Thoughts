# 新闻关注主题（News Agent 用此文件做相关性判断）

> 编辑指南：每条按"主题 + 解释 + 关键词"的格式写，越具体越好。
> Claude 会读这份文件来判断每条新闻是否值得推送，所以背景信息越充分越好。

## 一、行业智能化（核心主题）

**主题**：AI 在各行业的落地、产业格局、关键挑战、成功方法论。

**关注角度**：
- 哪些行业（制造、医疗、金融、零售、教育、能源、政务、法律…）在哪些场景率先实现 AI 落地
- 行业大模型 / 垂直模型 / 行业知识库 / RAG 在企业的真实部署案例
- 行业 AI 项目的 ROI、失败教训、客户案例
- 标杆企业的智能化转型路径
- 行业 AI 的政策、标准、监管

**关键词**：行业大模型、行业智能化、AI 落地、产业 AI、企业 AI、AI 转型、智能制造、AI+医疗、AI+金融、AI Agent 在企业、垂直 AI、Vertical AI

## 二、AI 产业格局

**主题**：硬件（算力）、模型层、应用层三层的价值流动、商业化、估值变化。

**关注角度**：
- 英伟达、AMD、华为昇腾、寒武纪等算力公司动态
- OpenAI、Anthropic、Google、Meta、DeepSeek、Qwen、智谱、月之暗面等模型公司动态
- AI 应用公司（Cursor、Perplexity、ChatGPT、Manus、Devin 等）的收入、增长、商业化数据
- AI 产业链各环节的资本开支、营收、利润、估值比较
- "AI 泡沫"相关的严肃讨论（非情绪化标题党）

**关键词**：AI capex、AI 算力、AI infra、Foundation model、AI 应用、AI ARR、AI valuation、AI bubble

## 三、Agent 与编程智能

**主题**：AI Agent 的技术演进与产业化，特别是编程类 Agent。

**关注角度**：
- Claude Code、Cursor、Windsurf、Devin、Codex 等编程 Agent 进展
- 多 Agent 系统、Agent 框架（LangGraph、AutoGen、CrewAI 等）
- Agent 在企业的真实落地案例（不是 demo）
- Agent 安全、评测、可观测性

**关键词**：AI Agent、Coding agent、Agentic AI、Multi-agent、Agent SDK、MCP、Computer use

## 四、过滤规则（请勿推送）

- 纯模型跑分、benchmark 对比，除非有产业意义
- 公司内部八卦、人事变动，除非是关键人物（CEO/CTO/首席科学家）
- AI 绘画 / AI 视频的纯娱乐应用
- 加密货币、Web3、元宇宙相关
- 标题党、营销软文、纯翻译稿
- 已经超过 48 小时的旧闻
