**ReAct 循环详解：**
```
                    ┌───────────────┐
                    │  用户指令/目标  │
                    └───────┬───────┘
                            ▼
              ┌─────────────────────────┐
              │  Think（思考/推理）        │
              │  • 分析当前状态           │
              │  • 确定下一步行动         │
              └────────────┬────────────┘
                           ▼
              ┌─────────────────────────┐
              │  Act（行动/工具调用）      │
              │  • 调用 MCP 工具         │
              │  • 执行代码/API          │
              └────────────┬────────────┘
                           ▼
              ┌─────────────────────────┐
              │  Observe（观察/处理结果）  │
              │  • 解析返回数据           │
              │  • 更新状态              │
              └────────────┬────────────┘
                           ▼
                   ┌──────────────┐
                   │  任务完成？    │──── 是 ──→ 输出最终结果
                   └──────┬───────┘
                          │ 否
                          ▼
                   回到 Think 继续循环
```
